# Netormium Brand Identity

## Brand idea

Netormium is a lightweight browser for connected Java feature phones. Its identity is inspired by planet Earth: one small globe representing a large, interconnected web.

## Logo direction

Create an original, compact globe symbol that remains legible at 15x15, 16x16, 24x24, and 32x32 pixels.

- Primary silhouette: a circular globe.
- Internal detail: two or three simplified curved longitude/latitude strokes, or a subtle network arc.
- Avoid tiny continents, thin hairlines, gradients that collapse at low color depth, and details that disappear on monochrome displays.
- The mark must work in one color, reversed, and on light/dark backgrounds.
- Do not reuse Opera's red ring/O mark or any Opera artwork.

## Color system

| Token | Color | Use |
|---|---|---|
| Ocean | #1769AA | Primary action and active selection |
| Deep Ocean | #102840 | Headers and high-contrast text |
| Sky | #E8F0F8 | Address bar and browser chrome |
| Globe Green | #2E9D68 | Optional secondary accent |
| Paper | #FFFFFF | Main surface |
| Ink | #202020 | Body text |
| Muted | #666666 | Status and secondary labels |
| Border | #A0A0A0 | Low-cost separators |

Keep the palette restrained for old LCD panels. The UI must remain understandable if colors are reduced or unavailable.

## Voice and naming

- Product name: Netormium
- Home screen: Start Page
- Quick launch collection: Speed Dial
- Main action: Open
- Browser menu: Menu
- Use short labels that fit narrow screens.
- Never use Opera product names or logos in Netormium UI, package metadata, splash screens, or shipped resources.

## UI principles

- Familiar compact J2ME browser layout.
- Strong hierarchy: address/navigation, page content, then softkey actions.
- Small, readable system fonts and high-contrast selection.
- One primary accent color; avoid excessive decoration.
- The globe mark is a brand cue, not a replacement for clear text labels.
